========================================================================
 agnes-hub-go  Windows 绿色版
========================================================================

Agnes AI 多账号聚合中转 + RPM 限流排队网关

本压缩包是「绿色版」：解压即用，不需要安装 Go、不需要任何运行时依赖，
也不需要管理员权限。支持 Windows 10 / 11（64 位）。

------------------------------------------------------------------------
一、快速开始
------------------------------------------------------------------------

1. 把整个压缩包解压到任意目录（路径不要含特殊字符）。
2. 双击 agnes-hub-go.bat。
3. 浏览器打开控制台：

       http://127.0.0.1:4142/console

4. 首次登录用默认管理员密码 admin123，登录页会提示「首次登录请改密」，
   进去后立刻在「系统」里改成自己的密码（改密后所有已登录会话立即失效）。
5. 在「账号池」里添加你的 Agnes 账号（名称 / API Key / 账号类型 / 上游地址），
   再到「密钥」Tab 签发一把下游密钥，就可以接入客户端了：

       Base URL   http://127.0.0.1:4142/v1
       API Key    控制台签发的那把 sk-agnes-xxxx
       Model      agnes-auto

关闭启动窗口即停止服务：本程序不注册 Windows 服务、不设开机自启。

------------------------------------------------------------------------
二、压缩包内容
------------------------------------------------------------------------

    agnes-hub-go.exe     主程序（单文件、无运行时依赖）
    agnes-hub-go.bat     一键启动脚本（端口预检 + 缺 exe 时尝试本机编译）
    README.txt           本说明

------------------------------------------------------------------------
三、端口
------------------------------------------------------------------------

默认监听端口：4142（仅本机 127.0.0.1）。
控制台地址：  http://127.0.0.1:4142/console
健康检查：    http://127.0.0.1:4142/healthz

若端口被占用，bat 会打印出占用记录并给出处理办法，而不是抛系统英文错误。

想让局域网内其它机器也能访问，启动脚本里的 HOST 改为 0.0.0.0
（或设环境变量 AGNES_HUB_HOST=0.0.0.0）。
注意：一旦对外开放，务必先改掉默认密码。

------------------------------------------------------------------------
四、数据目录
------------------------------------------------------------------------

所有运行期数据都在 exe 同级的 data\ 目录里（首次启动自动创建），
全部是 JSON / JSONL 文本文件，直接复制走即为完整备份：

    data\settings.json          全局设置（含管理员口令散列）
    data\accounts.json          账号池（含上游 API Key，注意保密）
    data\downstream_keys.json   签发的下游密钥
    data\bindings.json          会话粘性绑定
    data\video_jobs.json        视频任务映射
    data\usage.jsonl            用量日志

------------------------------------------------------------------------
五、升级：内置自更新（AGNES_HUB_UPDATE_REPO）
------------------------------------------------------------------------

程序默认会向发布仓库的 GitHub Releases 查询新版本，在控制台「系统」Tab
里可以手动检查并一键更新。替换过程由程序自带的助手进程完成，无需人工干预。

可用环境变量 AGNES_HUB_UPDATE_REPO 覆盖自更新行为：

    AGNES_HUB_UPDATE_REPO=owner/repo   跟随指定仓库的 Release
    AGNES_HUB_UPDATE_REPO=off          完全关闭自更新
    AGNES_HUB_UPDATE_REPO=none         （同上，关闭）
    AGNES_HUB_UPDATE_REPO=disabled     （同上，关闭）
    设成空值同样关闭

在 bat 里设置的办法：编辑 agnes-hub-go.bat，在 `set "BIN=agnes-hub-go.exe"`
下面加一行

    set "AGNES_HUB_UPDATE_REPO=off"

只想手动升级时，直接下载新版 zip 覆盖 exe 即可（记得保留 data\ 目录）。

------------------------------------------------------------------------
六、常见问题
------------------------------------------------------------------------

Q: 双击 bat 一闪而过？
   多为端口被占用或缺少 exe。改为在目录里打开 cmd，执行 agnes-hub-go.bat
   查看完整输出。

Q: 忘记管理员密码了？
   先停服务，备份 data\，再把 data\settings.json 里的 admin_password_hash 与
   admin_password_salt 两个字段清空（写成 ""），重启后即回落到默认密码
   admin123，并重新置上「首次登录请改密」。

Q: 杀毒软件报未知程序？
   本程序为自编译 Go 单文件二进制，未做代码签名。若被拦截，请自行放行。

Q: 自更新提示失败？
   自更新需要能访问 GitHub。网络受限时请改用手动下载新版覆盖，
   或设置 AGNES_HUB_UPDATE_REPO=off 关闭自更新。

Q: 换电脑怎么迁移？
   把整个目录（含 data\）拷过去即可，配置与账号全在 data\ 里。
